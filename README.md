# CashTrackr

CashTrackr is a fullstack web application for managing personal finances. Users can create an account, set budgets, and manage their expenses through a centralized interface.

The project was developed as the second project of a Fullstack development course focused on Node.js, TypeScript, Express, React, and Next.js.

## Overview

CashTrackr provides users with tools to organize and manage their personal expenses.

### Main features

* User registration and authentication.
* Creation and management of budgets.
* Expense management.
* Personal finance tracking through a centralized interface.

## Architecture

The application is structured as a fullstack project with a **Next.js frontend** and a separate **Express backend**.

The backend uses **Sequelize as an ORM** to interact with the PostgreSQL database.

## Technologies

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS

### Backend

* Node.js
* Express
* TypeScript

### Database

* PostgreSQL
* Sequelize — ORM

### Deployment

* Vercel — frontend deployment
* Render — backend deployment
* Supabase — PostgreSQL database hosting

## Project Context

CashTrackr was developed as the second project of a Fullstack development course.

Compared with the previous project, DevTree, this project introduced more advanced concepts such as application architecture, a more robust backend, and secure authentication.

The project was used to practice building and deploying a fullstack application using Next.js, Express, TypeScript, PostgreSQL, and Sequelize.
